# 添加树叶
## Overview
在`./knowledge-trees`文件夹下，存储着用户的“知识树”。当用户与AI助手聊天的过程中学习到了新知识，可以将其整理为“树叶”添加到知识树中。本技能可以使用以下步骤向“知识树”中增加新的“树叶”（片段性的知识）：
- 从对话中提取有价值的知识点
- 判断属于哪个知识树（查 index.md）
- 调用 append_leaf 添加树叶
## Instructions
### 1. 提取知识点
将用户指定的会话总结成待整理知识片段。待整理知识片段的格式为三级标题，包含日期、标题和正文：
1. 请模仿`/skills/append-leaf/references/knowledge-tree-example.md`中的“## 待整理”区域的格式进行内容的组织
2. 日期：可使用`get_current_date` tool获取当前的日期
3. 标题和正文：
    - 对于普遍意义上的知识，尽量将会话中包含的知识整理为通用性更强的讲解。举例时不要带有当前上下文中才包含的背景信息，如项目代码、用户的投资计划等。
    - 当用户明确要求将上下文中的私人背景信息也加入到知识片段中时，不要拒绝。这种情况一般出现与生活感悟、人生哲学思辨、心理疗愈等与个人经历相关的知识树积累。
### 2. 判断树叶归属并添加树叶
#### 索引文件
`./knowledge-trees/index.md`是知识树的索引文件，记录所有知识树及其主题。
- 如果索引文件不存在：
    - 知识树文件夹下也没有知识树，说明工作区处于初始化状态，添加第一个知识树和树叶后进行索引文件的添加。
    - 知识树文件夹下有知识树文件，了解当前知识树存储区的文档结构后，调用`update_index`为知识树们创建索引文件。
#### 添加树叶
1. `append_leaf(path: str, tree_name: str, content: str)`：将内容追加到指定路径的知识树文件中的"待整理"区域，如果文件不存在则创建。**注意：path 参数必须是一个有效的文件路径，例如 './python_knowledge.md' 或 'knowledge.md'，不能为空。文件名建议用主题命名，如 python.md / psychology.md。**。请确保追加的内容格式正确，避免破坏知识树结构。
2. 如果索引中已存在合适的知识树存放树叶，直接调用`append_leaf`添加当前树叶至知识树末尾
3. 如果不存在合适的知识树，向用户提出新知识树的名称建议，询问用户是否要新建知识树。
    1. 如果用户同意建议，调用`append_leaf`新建知识树并添加树叶
    2. 如果用户希望换个名字，调用`append_leaf`新建知识树时传入用户提议的名字
    3. 成功新建知识树后，调用`update_index`更新索引文件。请注意`update_index`的content参数是覆盖式写入，需先grep/读现有 index.md，再在其基础上补齐新行、修改已有文本、整体传入。
